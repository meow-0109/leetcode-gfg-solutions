```java
class Solution {    
    public int findTargetSumWays(int[] nums, int target) {        
        return helper(nums, target, 0,  0);                    
    }    
    //base case
    public int helper(int[] nums, int target, int currSum,  int currIndex){
        if(currIndex  == nums.length){            
            return currSum == target ? 1: 0;                         
        }                
        return     helper(nums, target, currSum + nums[currIndex],  currIndex+1) +
            helper(nums, target, currSum - nums[currIndex],  currIndex+1);                        
    }
}
```
Recursive tree
```
                   0
                 /   \
               +1     -1
              1       -1
             / \      / \
          +1  -1   +1  -1
           2   0    0  -2
```
Time Complexity

Each element has:

2 choices
(+ or -)

For n elements:

2 × 2 × 2 × ... × 2

n times

O(2^n)

This is why larger inputs need memoization/DP to avoid recalculating the same (currIndex, currSum) states.
